Bonus educațional: verificările sunt emulate, nu rulează GitHub Actions.
01
Git ≠ GitHub

Git = istoricul local. GitHub = platformă pentru repo-uri, PR-uri și colaborare.

02
Commit ≠ Push

Un commit este local. Colegii îl văd după ce publici cu git push.

03
Branch ≠ Folder

Un branch este o referință mobilă la un commit, nu o copie completă a proiectului.

04
PR ≠ Merge automat

Un PR propune o schimbare; review-ul și integrarea sunt pași distincți.
