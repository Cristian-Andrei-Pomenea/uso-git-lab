# GIT//LAB 08 — Git Universe

Masterclass interactiv de Git și GitHub pentru **USO, anul I** (Laboratorul 08).

## Ce include proiectul

- **Git Playground** — terminal simulat + graf animat cu staging, commit-uri, branch-uri, merge, PR și conflicte.
- **Masterclass** — lecții și misiuni proiectabile pentru 30–60 minute.
- **Git real, separat** — sandbox local sigur pentru demo cu două clone.
- **ARENA (multiplayer)** — profesorul pornește o sesiune, studenții intră prin QR/PIN, puncte pentru răspunsuri corecte + viteză, podium și clasament.

> Implementarea este publicată incremental; nu considera funcțiile disponibile până când fișierele și testele respective apar în repository.

Material pedagogic bazat pe [Laboratorul USO 08](https://ocw.cs.pub.ro/courses/uso/laboratoare/laborator-08).
